# Privacy Policy for Backyard Beagles

**Effective Date:** November 13, 2026  
**Developer:** Eric Barber (`com.ebarber972.beagles`)

## 1. Overview
**Backyard Beagles** is an offline, free-to-play backyard beagle slot-style arcade game. We respect your privacy and designed the application so that it operates entirely on your device without collecting, transmitting, or sharing any personal data.

## 2. Information Collection and Use
- **No Personal Data Collected:** Backyard Beagles does **not** collect names, email addresses, phone numbers, precise or approximate location data, device identifiers, advertising IDs, or usage telemetry.
- **No Network Requirement:** The application does not request `android.permission.INTERNET` and makes zero network requests to external servers.
- **Local Device Storage Only:** Game progress (such as virtual "Treats" balance, level/XP, unlocked badges, audio mute preference, turbo speed preference, and interrupted-spin recovery state) is stored strictly on your device using local application storage (`localStorage`). Clearing the app's storage or uninstalling the app permanently removes this local data.

## 3. Virtual Currency ("Treats") & Simulated Gambling Disclosure
- All in-game credits ("Treats") are **100% free virtual play money** with **no real-world monetary value**.
- Backyard Beagles does **not** offer real-money gambling, in-app purchases (IAP), real-money payouts, cash-outs, or physical prizes.

## 4. Third-Party SDKs and Advertising
Backyard Beagles contains **no third-party analytics SDKs, no crash-reporting trackers, and no advertising networks**.

## 5. Children's Privacy & Intended Audience
Because Backyard Beagles features simulated slot-machine mechanics using virtual dog treats, it is intended for a general/adult audience in accordance with Google Play's Simulated Gambling content ratings and is not directed at children under 13. We do not knowingly collect any personal information from anyone, including children.
